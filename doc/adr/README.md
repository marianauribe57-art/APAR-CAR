# Registro de decisiones de arquitectura (ADR)

Cada decisión técnica relevante del proyecto se documenta aquí como un
archivo independiente, en formato `ADR-XXX-titulo.md`.

Las decisiones vigentes del proyecto (ADR-003 a ADR-007) se migrarán a
este formato. ADR-008 (lenguaje de servidor y framework) está pendiente
y se resuelve en la fase de diseño y arquitectura.
